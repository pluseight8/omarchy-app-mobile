# Плагин OmaApp для Omarchy

Это компонент OmaApp для Omarchy. Сейчас он устанавливает один виджет состояния, который сообщает, что сопряжение пока недоступно. Он не открывает сетевой порт и не выполняет удалённые команды.

## Установка

В каталоге клона репозитория OmaApp выполните:

    ./omarchy-plugin/install.sh

Скрипт копирует плагин в пользовательский каталог Omarchy, проверяет манифест средствами Omarchy и включает плагин. Отдельный сервер или системная служба не устанавливаются.

Для удаления выполните:

    ./omarchy-plugin/uninstall.sh

Удаление выключает плагин и переносит его исходники в резервный каталог с меткой времени.

## Текущие ограничения

- Сопряжение, обнаружение, синхронизация тем, передача файлов, буфер обмена, уведомления, терминал и удалённый рабочий стол пока не реализованы.
- Виджет только показывает состояние.
- Перед включением сетевого протокола версии Android-приложения и плагина должны совпадать.

Сторонние плагины Omarchy выполняются как QML внутри долгоживущего процесса shell. Перед включением прочитайте и проверьте исходный код.
